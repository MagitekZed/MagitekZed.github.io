ZeD-T Labs · hobby projects

I've spent 14 years in security operations, most of them at HackerOne. In my spare time I build things with AI coding tools: games, tools for the tabletop games I play, data visualizations, and small utilities that fix one specific annoyance.

None of this is professional software. These are hobby projects, most of them started because I wanted the thing to exist. This page is where they live.

how these get made

I describe what I want, an AI coding agent (usually Claude Code) writes most of the code, and I test it, break it and redirect it until it works the way I pictured. I'm not a software engineer. I bring the idea, the testing, and a lot of opinions about how things should work.

where they run

Most of these run entirely in your browser, with no account and nothing to install. A few use Supabase for multiplayer or syncing between screens, one is a command-line tool, and one is a desktop app.

Projects marked "source private" still have working live sites. Only the code isn't public.
